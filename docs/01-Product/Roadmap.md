# Zebraz — Product Roadmap

> The long-term evolution of Zebraz from a desktop AI companion into a more capable AI system.

---

## 🟡 Phase 1 — Core Desktop Assistant

**Status:** Nearing completion

Build the foundation of Zebraz as a macOS desktop AI companion.

### Focus

- Global hotkey activation
- Gemini integration
- PyQt6 chat interface
- Shimeji-style desktop pet
- Desktop wandering
- Conversation handling
- Basic memory
- Stable macOS desktop behavior

### Goal

A reliable desktop AI assistant that the user can interact with without opening a traditional chatbot application.

---

## ⚪ Phase 2 — RAG Knowledge Assistant

**Status:** Planned

Give Zebraz the ability to work with external knowledge and user-provided information.

### Potential capabilities

- Document ingestion
- Document chunking
- Embeddings
- Vector database
- Retrieval
- Context injection
- Source-aware responses

### Goal

Allow Zebraz to answer questions using a controlled knowledge base rather than relying only on the LLM's built-in knowledge.

---

## ⚪ Phase 3 — Agent Tool Use

**Status:** Planned

Move from a chatbot toward an AI agent capable of using tools.

### Planned direction

- Agent framework
- Tool definitions
- Tool execution
- Planning
- Multi-step tasks
- External actions

**Planned framework:** AutoGen

### Goal

Allow Zebraz to perform tasks rather than only respond to messages.

---

## ⚪ Phase 4 — Multi-Agent Collaboration

**Status:** Planned

Introduce multiple specialized agents that can collaborate on complex tasks.

### Goal

Use specialized agents for different types of tasks while maintaining a unified user experience.

---

## ⚪ Phase 5 — AI Code Review Agent

**Status:** Planned

Introduce software-engineering capabilities into Zebraz.

### Potential capabilities

- Analyze source code
- Identify bugs
- Detect code smells
- Suggest improvements
- Review pull requests
- Explain code
- Generate tests
- Analyze architecture

### Goal

Turn Zebraz into an AI development companion capable of understanding and reviewing software projects.

---

## ⚪ Phase 6 — Face Recognition + Advanced Memory

**Status:** Planned

Explore more personalized interaction through visual recognition and advanced memory.

### Potential capabilities

- Face detection
- Face recognition
- User identification
- Long-term memory
- Context-aware personalization
- Interaction history

### Goal

Explore how Zebraz could maintain a richer understanding of the user and their interactions.

---

# Roadmap Principles

## Build Incrementally

Each phase should build on the previous phase rather than attempting to implement everything at once.

## Understand Before Abstracting

New technologies should be introduced when they solve a real problem in the project.

## Keep the Core Simple

The desktop assistant should remain lightweight even as its AI capabilities become more sophisticated.

## Validate Before Moving Forward

A phase should be reasonably stable and understood before the project moves to the next major phase.
